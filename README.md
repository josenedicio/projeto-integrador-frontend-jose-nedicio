O tema do projeto será apresentar um top 3 popular dos considerados maiores cantores de sertanejo no Brasil, apresentando dados, algumas curiosidades, além das músicas mais amadas dos cantores. O amor pelo sertanejo representa uma forte conexão com a cultura e as tradições do interior. Esse estilo musical valoriza o sentimento, fazendo com que as pessoas sintam "dentro da alma" as canções.
